Sill Weather

Choose a weather service

Sill uses Apple Weather by default and needs no key. Your own commercial Open-Meteo Customer API key is required only when you explicitly select Open-Meteo.

Updated October 21, 2026Key stays in this Mac's Keychain
Do not use the Open-Meteo Free API: Its public hosted API is limited to non-commercial use. For Sill, purchase a Customer API plan and use the commercial API key issued for that plan.

Apple Weather (default)

No account or API key is required. Open Weather → Settings, set Weather service to Apple Weather, choose Current Location or search for a city, then save.

  1. Allow macOS location access for Current Location, or search for and select a city.
  2. Choose Celsius or Fahrenheit and save.
  3. Forecasts and attribution are supplied by Apple Weather.
Apple Weather attribution

Open-Meteo Customer API

This is an optional bring-your-own-key service. Purchase a commercial Customer API plan directly from Open-Meteo; Sill does not provide, resell, or share API usage.

  1. Choose a Customer API plan on the Open-Meteo Pricing page and obtain the API key after subscribing.
  2. In Sill, open Weather → Settings and switch Weather service to Open-Meteo (API Key).
  3. Paste the commercial API key into API Key, choose a location and temperature unit, then save. Sill sends forecast requests to customer-api.open-meteo.com.
Pricing & Customer APITermsData licence & attribution

Plans, quotas, and terms can change; use Open-Meteo's official pages as the current source. Paid API use still requires Open-Meteo / CC BY 4.0 attribution, which Sill shows in the Weather interface.

API key safety

Sill stores the Open-Meteo key in this Mac's Data Protection Keychain. Weather settings keep only a random reference—not the plaintext key—and the key is not synced through iCloud.

  • Create a separate, revocable key for Sill and set an appropriate quota or budget in Open-Meteo.
  • Never enter the key on this website or include it in support email, screenshots, or source repositories.
  • If a key leaks, revoke it in Open-Meteo first, then remove and replace it in Sill.

Data flow

City search uses Apple geocoding for both services. Apple Weather sends approximate coordinates to Apple; Open-Meteo sends approximate coordinates and the commercial API key directly to Open-Meteo. macOS asks for location permission before Current Location is used.
