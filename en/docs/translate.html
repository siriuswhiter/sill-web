Sill Translate

Set up a translation service

Choose a provider you trust, create your own API key, then store it securely in Sill. Sill does not sell API usage and never asks you to enter a key on this website.

Updated October 19, 2026Official linksKeys stay in this Mac's Keychain

Before you start

In Sill, open Translate → Settings, add a service, then open its setup guide. Enter the required API Key, Model, and Region, then choose Test Service. The test sends the fixed text “Hello” and may use a small amount of quota.

Subscriptions are not API credit: Consumer plans such as ChatGPT Plus, Gemini Advanced, and DeepL Translator generally do not include developer API usage. Activate the provider's API product separately.

MyMemory

No account or API key is required, so it is useful for trying Translate. It is a public third-party service: the full source text leaves your Mac and public daily limits apply.

  1. Add MyMemory in Sill and make it the default service.
  2. Leave the Key field empty and test the connection.
  3. Do not submit passwords, tokens, private messages, or confidential work.

DeepL API Free / Pro

Requires a DeepL API plan and API key. A regular DeepL Translator subscription is not an API plan, and Free and Pro use different endpoints.

  1. Activate DeepL API Free or API Pro.
  2. Create a separate key for Sill on the API Keys page and set a usage limit.
  3. Choose the matching DeepL preset in Sill, paste the key, and test it.

Microsoft Translator

Requires an Azure Translator resource. A global resource needs only a key; a regional or multi-service resource also needs Region.

  1. Create a Translator resource in Azure and choose a pricing tier.
  2. Open Keys and Endpoint for the resource and copy a key. Enter Region only when the resource shows one.
  3. Keep Sill's default API URL, enter the key and optional Region, then test.

Google Cloud Translation Basic v2

Requires a Google Cloud project, Cloud Billing, the enabled Cloud Translation API, and a key restricted to that API. A Gemini AI Studio key does not work here.

  1. Create or select a project, attach Billing, and enable the Cloud Translation API.
  2. Create an API key in Credentials and restrict it to the Cloud Translation API.
  3. Paste the key into Sill's Google Cloud Translation service and test it.

OpenAI API

A ChatGPT subscription does not include API billing. You need a developer-platform API key, active Billing or balance, and a currently supported Model ID.

  1. Create a project API key on the developer platform and configure API Billing.
  2. Choose a Model ID that supports Chat Completions from the official model list.
  3. Enter the API Key and Model in Sill, keep the default API URL, and test.

DeepSeek API

Requires a DeepSeek Platform key, available balance, and a Model ID. Sill already supplies the OpenAI-compatible API URL.

  1. Register on DeepSeek Platform and create an API key.
  2. Confirm the account has available balance and copy a Model ID from the official docs.
  3. Enter the key and Model in Sill, then test.

Gemini Developer API

Uses a Google AI Studio key and Gemini Model ID. It is not Google Cloud Translation and is separate from a consumer Gemini subscription.

  1. Create or import a project API key in Google AI Studio.
  2. Choose a current Model ID from the OpenAI compatibility guide.
  3. Enter the key and Model in Sill. Do not use a Cloud Translation key.

Qwen · Alibaba Cloud Model Studio

Sill's current preset uses the Mainland China (Beijing) endpoint. API Key, Model, and endpoint must use the same Region; an international key does not work with this preset.

  1. Activate Model Studio in the Beijing region.
  2. Create a DASHSCOPE_API_KEY in the same region and choose a Model ID available there.
  3. Enter the key and Model in Sill, keep the Beijing API URL, and test.

SiliconFlow

Requires a SiliconCloud API key and the complete Model ID shown in the model catalog. Free models, promotional balance, and pricing vary by model.

  1. Sign in to SiliconCloud and create a separate key on the API Keys page.
  2. Copy the complete Model ID from the model catalog.
  3. Enter the key and Model in Sill, then test.

Volcengine Ark

First activate the model in Ark, then create an API key for the current project and enter the matching Model ID. Sill's preset uses the Beijing API URL.

  1. Activate the target model under Activation Management and confirm the current project.
  2. Create a project API key and restrict it to the required model and callers where possible.
  3. Copy the Model ID, enter the key and Model in Sill, then test.

Custom OpenAI-compatible

For an OpenAI-compatible provider or self-hosted gateway you trust. Sill can test protocol compatibility, but it cannot verify the operator, logging, retention, or billing practices of that server.

  1. Get the HTTPS API base URL, API key, and Model ID from the provider.
  2. Do not include `/chat/completions`, query parameters, or credentials in the API URL. Sill appends the path.
  3. Test only after you trust the service. A passing test does not prove privacy or billing safety.

There is no universal signup, Billing, Pricing, or API Keys page. Use the provider's own official documentation.

API key safety

Sill stores keys in this Mac's Data Protection Keychain and does not sync them through iCloud. During translation, the key is sent directly to your selected provider.

  • Create a separate, revocable key for Sill. Do not reuse a key from an important project.
  • Use the provider console to restrict APIs, models, Region, source IPs, quota, or budget where supported.
  • Never include a key in support email, screenshots, recordings, source repositories, or this website.
  • If a key leaks, revoke it immediately in the provider console, then replace it in Sill.
