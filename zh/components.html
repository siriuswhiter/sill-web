收纳与内容库

Pro

先收下文件、图片、文字和链接，再搜索、整理或带到其他应用。

不限项目数量，支持标签、编辑、固定、批量操作与最近删除恢复，也可保护敏感内容、搜索图片和 PDF 中的文字（OCR）。

文件

Free

浏览你选择的本地文件夹。

首次选择文件夹需要授权；你可以重新选择无法访问的目录。

时钟

Free

把当前时间留在岛上，一眼就能看到。

可与其他组件组合使用。

天气

Free

在 Island 查看所选地点的天气。

需要联网；使用当前位置时会请求定位授权。

番茄钟

Pro

开始一段专注时间，查看进度并安排休息。

支持提醒设置；相关系统提醒可能需要授权。

照片

Pro

让自己喜欢的照片成为 Island 的一部分。

由你选择照片或来源。

打开工具，把事做完。

Note

Pro

记下临时想法或一小段文字，留待之后处理。

在本机保存，也可从 Note 中继续处理内容。

应用

Free

浏览和启动常用应用，减少来回寻找。

应用启动使用 macOS 已安装的应用。

剪贴板

Pro

找回复制过的文本、链接和图片。

历史记录默认关闭。启用后在本机加密保存，可排除应用、设定保留期限或随时清空。

翻译

Pro

输入文字，在岛上查看与复制译文。

需要联网；文字会发送到你选择的翻译服务。部分服务需要自己的 API 凭据并可能单独收费。

查看翻译服务配置指南
