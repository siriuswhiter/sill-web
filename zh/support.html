常见恢复方法

  • 误删内容：Free 与 Pro 都可在删除后立即点“撤销”。Pro 还可在 7 天内从“最近删除”恢复；所有用户均可确认后永久删除。
  • 引用文件找不到：原文件被移动、改名或权限失效时，选择“重新定位引用文件…”并选中原文件，即可恢复访问。
  • Pro 批量操作部分失败：打开失败详情检查原文件、访问权限和存储位置，然后选择“重试失败项”；已成功的项目不会重复执行。
  • Pro 编辑尚未保存：切换内容或离开编辑器时，选择保存、放弃或取消。若保存失败，Sill 会保留草稿；修复存储问题后可再次保存。
  • Pro 快捷键冲突：在“设置 → 通用”重新录制快捷键。若新组合无效，Sill 会保留之前可用的快捷键；Free 始终使用默认的显示 / 隐藏快捷键。
  • 置物岛出现在错误屏幕：Pro 可在“设置 → 通用 → 置物岛显示器”选择目标显示器或“自动选择”；Free 使用自动选择。

反馈时建议提供的信息

  • 您的 macOS 系统版本（如 macOS 14.5 或 macOS 15.0）以及 Mac 硬件型号（MacBook Pro 刘海屏或 Mac mini / 外接显示器）
  • 发生异常时的具体操作流程：如文件拖入、拖出、长存固定、批量操作、恢复内容、重新定位文件或按全局快捷键抓取剪贴板
  • 若有屏幕录屏或截图更佳

隐私与购买支持

如需咨询隐私政策、账号删除或 App Store 购买恢复异常，请在来信主题中写明“隐私咨询”“账号删除”或“购买恢复”。核心功能无需登录；登录用户也可直接在设置 > 账号中删除 Sill 账号。切勿在邮件中发送任何系统密码、Apple ID 凭据或完整财务敏感信息。

系统要求与兼容性

需要 macOS 14 (Sonoma) 或更高版本。Sill 是原生 macOS 应用，作为常驻菜单栏与屏幕顶部的轻量配件运行，平时不占用 Dock 位置。
