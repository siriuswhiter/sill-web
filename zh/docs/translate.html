Sill Translate

配置翻译服务

选择你信任的服务，创建自己的 API Key，再把它安全地存入 Sill。Sill 不出售 API 额度，也不会要求你在这个网页输入密钥。

更新于 2026-10-19官方链接密钥保存在本机 Keychain

开始之前

在 Sill 中打开「Translate → Settings」，添加服务，然后打开对应的配置指南。填写必要的 API Key、Model 和 Region 后，先点「Test Service」；测试会发送固定的 “Hello”，并可能消耗少量额度。

订阅不等于 API：ChatGPT Plus、Gemini Advanced、DeepL Translator 等消费者订阅通常不包含开发者 API 额度。请在对应的开发者平台单独开通。

MyMemory

无需注册或 API Key，适合先体验；它是公共第三方服务，完整原文会离开这台 Mac，并受公共每日额度限制。

  1. 在 Sill 添加 MyMemory 并设为默认服务。
  2. 无需填写 Key；直接测试连接。
  3. 不要提交密码、Token、私人通信或公司机密。

DeepL API Free / Pro

需要 DeepL API 套餐和 API Key。普通 DeepL Translator 订阅不是 API 套餐；Free 与 Pro 必须使用各自对应的 endpoint。

  1. 开通 DeepL API Free 或 API Pro。
  2. 在 API Keys 页面为 Sill 创建单独的 Key，并设置 usage limit。
  3. 在 Sill 选择与套餐匹配的 DeepL preset，粘贴 Key 并测试。
API plansAPI KeysAuthenticationKey management

Microsoft Translator

需要 Azure Translator resource。Global resource 只需 Key；regional 或 multi-service resource 还需要填写 Region。

  1. 在 Azure 创建 Translator resource 并选择计费层。
  2. 打开 resource 的 Keys and Endpoint，复制 Key；仅在页面给出 Region 时填写 Region。
  3. 在 Sill 保留默认 API URL，填写 Key 和可选 Region，然后测试。
Create a Translator resourceKeys, Endpoint & RegionPricing

Google Cloud Translation Basic v2

需要 Google Cloud project、Cloud Billing、已启用的 Cloud Translation API，以及限制到该 API 的 Key。Gemini AI Studio Key 不能用于这里。

  1. 创建或选择 project，关联 Billing，并启用 Cloud Translation API。
  2. 在 Credentials 创建 API Key，并把 API restriction 设为 Cloud Translation API。
  3. 把 Key 粘贴到 Sill 的 Google Cloud Translation 服务并测试。

OpenAI API

ChatGPT 订阅不包含 API 计费。你需要 developer platform 的 API Key、可用的 Billing/余额和一个当前支持的 Model ID。

  1. 在 developer platform 创建 project API Key，并配置 API Billing。
  2. 从官方模型列表选择支持 Chat Completions 的 Model ID。
  3. 在 Sill 填写 API Key 和 Model；保留默认 API URL 后测试。

DeepSeek API

需要 DeepSeek Platform Key、可用余额和 Model ID。Sill 已预设 OpenAI-compatible API URL。

  1. 注册 DeepSeek Platform 并创建 API Key。
  2. 确认账户有可用余额，并从官方文档复制 Model ID。
  3. 在 Sill 填写 Key 与 Model，然后测试。

Gemini Developer API

使用 Google AI Studio Key 和 Gemini Model ID。它不是 Google Cloud Translation，也不等同于 Gemini 消费者订阅。

  1. 在 Google AI Studio 创建或导入 project API Key。
  2. 从 OpenAI compatibility 文档选择当前可用的 Model ID。
  3. 在 Sill 填写 Key 和 Model；不要使用 Cloud Translation Key。

Qwen · Alibaba Cloud Model Studio

Sill 当前 preset 指向中国内地北京 endpoint。API Key、Model 和 endpoint 必须属于同一 Region；国际站 Key 不能直接用于这个 preset。

  1. 在阿里云百炼 / Model Studio 的北京地域开通模型服务。
  2. 创建同地域的 DASHSCOPE_API_KEY，并选择该地域可用的 Model ID。
  3. 在 Sill 填写 Key 和 Model，保留北京 API URL 后测试。

SiliconFlow

需要 SiliconCloud API Key 和模型广场中显示的完整 Model ID。免费模型、赠送余额和价格会随模型变化。

  1. 登录 SiliconCloud，在 API Keys 页面创建独立 Key。
  2. 从模型广场复制完整 Model ID。
  3. 在 Sill 填写 Key 与 Model，然后测试。

火山方舟

必须先在方舟开通目标模型，再创建当前 project 的 API Key，并填写对应 Model ID。Sill 的 preset 使用北京地域 API URL。

  1. 在「开通管理」开通目标模型，并确认当前 project。
  2. 创建 project API Key；尽量限制到所需模型和调用来源。
  3. 复制 Model ID，在 Sill 填写 Key 与 Model 后测试。

Custom OpenAI-compatible

用于你信任的 OpenAI-compatible 服务或自建网关。Sill 只能验证协议能否工作，不能验证服务器的运营方、日志、留存或计费安全。

  1. 从服务方取得 HTTPS API base URL、API Key 与 Model ID。
  2. API URL 不要包含 `/chat/completions`、query 参数或凭据；Sill 会自动追加路径。
  3. 确认服务可信后再测试；测试成功不代表隐私或计费安全。

没有通用的注册、Billing、Pricing 或 API Keys 页面；请使用服务方自己的官方文档。

API Key 安全

Sill 将 Key 保存在这台 Mac 的 Data Protection Keychain，不同步到 iCloud。翻译时，Key 会随请求直接发送给你选择的服务。

  • 为 Sill 创建单独、可撤销的 Key，不要重复使用重要项目的 Key。
  • 在 provider 控制台限制 API、模型、Region、来源 IP、quota 或预算（支持哪些限制取决于 provider）。
  • 不要把 Key 发给支持邮箱、截图、录屏、代码仓库或这个网站。
  • 发现泄露时，立即在 provider 控制台撤销 Key，再在 Sill 中替换。
