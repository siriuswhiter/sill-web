配置与使用指南

把下一步说清楚。

文档会直接说明要打开哪个控制台、填写哪个字段，以及数据会发送到哪里。你无需把密码或 API Key 交给这个网站。

安全边界：密钥只应粘贴到 Mac 上的 Sill 设置中；Sill 将它保存在这台 Mac 的 Keychain。

配置翻译服务

从免 Key 的 MyMemory 到 DeepL、Microsoft、Google 与 OpenAI-compatible 服务。

配置天气服务

默认使用 Apple 天气，或配置自己的 Open-Meteo 商业 Customer API Key。
