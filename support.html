添加组件或打开工具Add a component or open a tool

在 Sill 中选择需要的组件，查看预览和设置，再加入 Island。工具有自己的操作界面；可用放置位置随功能而定。

Choose a component in Sill, review its preview and settings, then add it to the Island. Tools have their own working views. Available placements depend on the feature.

某个组件不能启用A component will not activate

Apps、Files、时钟和天气包含在 Free 中；置物、Note、剪贴板、翻译、番茄钟、照片和岛上伙伴需要 Pro。请检查 Pro 状态以及该功能需要的权限或网络连接。

Apps, Files, Clock, and Weather are included with Free. Shelf, Note, Clipboard, Translate, Pomodoro, Photo, and companions require Pro. Check your access status and any permissions or network connection the feature needs.

翻译或天气没有结果Translation or weather has no result

检查网络连接。翻译请确认已选服务、API 凭据及服务额度；天气请确认地点，使用当前位置时检查定位权限。

Check your internet connection. For Translate, check the selected service, API credentials, and service quota. For Weather, check the selected location and location permission if you use your current position.

按服务查看 API Key 与模型配置步骤See provider-specific API key and model setup

管理剪贴板历史Manage clipboard history

历史记录默认关闭。开启后可排除应用、调整保留期限或随时清空。停用记录或 Pro 不可用时停止采集。

History is off by default. Once enabled, you can exclude apps, set retention, or clear it at any time. Recording stops when disabled or when Pro is unavailable.

内容误删或引用文件丢失Recover content or a missing file reference

删除后可立即撤销，也可在 7 天内从最近删除恢复。引用文件移动或权限失效时，使用重新定位命令再次选择原文件。

Undo a deletion immediately or restore it from Recently Deleted within 7 days. If a referenced file moves or loses permission, use the locate command to select the original file again.

调整快捷键或显示位置Adjust shortcuts or display placement

Free 与 Pro 都可修改外观、布局、快捷键和显示位置。若快捷键冲突，换用其他组合；若引用文件权限失效，请重新选择原文件。

Free and Pro both support appearance, layout, shortcuts, and display-placement settings. If a shortcut conflicts, choose another combination. Re-select the original file if its access permission has expired.

恢复试用或购买Restore a trial or purchase

使用原购买的 App Store 账号，在 App 的 Sill Pro 设置中恢复购买。恢复试用保留最初的开始时间，不会重新获得 7 天。

Use the original App Store account and restore purchases in the app’s Sill Pro settings. Restoring a trial keeps its original start date; it does not grant another seven days.

联系时可以告诉我们What to include when you write

请说明 macOS 版本、Mac 型号、涉及的组件或工具，以及问题出现前的操作步骤。截图或录屏也有帮助；请遮挡私人内容，不要发送密码、API 密钥或支付信息。

Include your macOS version, Mac model, the component or tool involved, and the steps leading to the issue. Screenshots or recordings help; hide private content and never send passwords, API keys, or payment details.

系统要求System requirements

Sill 支持 macOS 14 或更高版本，以及有刘海或无刘海的显示器。基础使用无需 Sill 账号，试用和购买由 App Store 处理。

Sill supports macOS 14 or later and displays with or without a notch. Core use needs no Sill account; trials and purchases are handled through the App Store.
