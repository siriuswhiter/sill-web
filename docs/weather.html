Sill WeatherSill Weather

选择天气服务Choose a weather service

Sill 默认使用 Apple 天气，无需填写 Key。只有在你主动选择 Open-Meteo 时，才需要自己的商业 Customer API Key。

Sill uses Apple Weather by default and needs no key. Your own commercial Open-Meteo Customer API key is required only when you explicitly select Open-Meteo.

不要使用 Open-Meteo Free API：Do not use the Open-Meteo Free API: 其公共托管 API 仅限非商业用途。用于 Sill 时，请购买 Customer API 套餐并使用该套餐提供的商业 API Key。Its public hosted API is limited to non-commercial use. For Sill, purchase a Customer API plan and use the commercial API key issued for that plan.

Apple 天气（默认）Apple Weather (default)

无需账户或 API Key。打开 Weather → Settings，将「天气服务」设为「Apple 天气」，选择当前位置或搜索城市，然后保存。

No account or API key is required. Open Weather → Settings, set Weather service to Apple Weather, choose Current Location or search for a city, then save.

  1. 使用「当前位置」时，允许 macOS 定位权限；也可以搜索并选择城市。Allow macOS location access for Current Location, or search for and select a city.
  2. 选择摄氏或华氏温度并保存。Choose Celsius or Fahrenheit and save.
  3. 天气预报与归属信息由 Apple Weather 提供。Forecasts and attribution are supplied by Apple Weather.

Open-Meteo Customer API

这是可选的 BYOK 服务。你需要直接向 Open-Meteo 购买商业 Customer API 套餐；Sill 不提供、转售或共享 API 额度。

This is an optional bring-your-own-key service. Purchase a commercial Customer API plan directly from Open-Meteo; Sill does not provide, resell, or share API usage.

  1. 在 Open-Meteo Pricing 页面选择 Customer API 套餐，完成订阅后取得 API Key。Choose a Customer API plan on the Open-Meteo Pricing page and obtain the API key after subscribing.
  2. 在 Sill 打开 Weather → Settings，将「天气服务」切换为「Open-Meteo (API Key)」。In Sill, open Weather → Settings and switch Weather service to Open-Meteo (API Key).
  3. 将商业 API Key 粘贴到 API Key 字段，选择地点与温度单位，然后保存。Sill 会向 customer-api.open-meteo.com 发起预报请求。Paste the commercial API key into API Key, choose a location and temperature unit, then save. Sill sends forecast requests to customer-api.open-meteo.com.
Pricing & Customer APITermsData licence & attribution

套餐、额度与条款可能变化，请以 Open-Meteo 官方页面为准。即使使用付费 API，展示天气数据时仍需保留 Open-Meteo / CC BY 4.0 归属信息；Sill 会在天气界面显示该归属链接。

Plans, quotas, and terms can change; use Open-Meteo's official pages as the current source. Paid API use still requires Open-Meteo / CC BY 4.0 attribution, which Sill shows in the Weather interface.

API Key 安全API key safety

Sill 将 Open-Meteo Key 保存在这台 Mac 的 Data Protection Keychain；天气配置只保存随机引用，不保存明文 Key，也不通过 iCloud 同步。

Sill stores the Open-Meteo key in this Mac's Data Protection Keychain. Weather settings keep only a random reference—not the plaintext key—and the key is not synced through iCloud.

  • 为 Sill 创建独立、可撤销的 Key，并在 Open-Meteo 控制台设置合适的额度或预算。Create a separate, revocable key for Sill and set an appropriate quota or budget in Open-Meteo.
  • 不要把 Key 输入这个网页、发送给支持邮箱、放入截图或提交到代码仓库。Never enter the key on this website or include it in support email, screenshots, or source repositories.
  • 发现泄露时，先在 Open-Meteo 撤销 Key，再在 Sill 中移除并替换。If a key leaks, revoke it in Open-Meteo first, then remove and replace it in Sill.

数据流向Data flow

两种服务的城市搜索都使用 Apple 地理编码。Apple 天气模式将近似坐标发送给 Apple；Open-Meteo 模式将近似坐标与商业 API Key 直接发送给 Open-Meteo。使用当前位置前，macOS 会请求你的定位许可。

City search uses Apple geocoding for both services. Apple Weather sends approximate coordinates to Apple; Open-Meteo sends approximate coordinates and the commercial API key directly to Open-Meteo. macOS asks for location permission before Current Location is used.
