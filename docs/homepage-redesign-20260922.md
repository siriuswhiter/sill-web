# Sill 首页视觉调整

采用 Sill 自有的雾白底色、海玻璃青绿点缀、横向轻量导航与左右分栏首屏。预览展示悬浮置物架，泡泡作为陪伴角色；保留功能定位和即将上线状态。

## 实现

- 首页使用独立 home.css 与 home-preview.css，不再叠加旧版首页主题。
- 首屏以置物岛演示为重点，演示支持重播与减少动态效果。
- 新增森林、海底、星空静态场景预览切换，按钮提供 aria-pressed 状态。
- 精简 Free / Pro 展示，明确额外皮肤包需单独购买并持有永久 Pro。
- FAQ 与移动导航使用原生 details；移动导航支持选择后关闭及 Escape 关闭。
- 同步中英预渲染页、站点事实与 llms-full.txt。
- 不加载外部字体、统计脚本或参考站素材；无新增依赖。
