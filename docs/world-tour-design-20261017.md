# 彩虹赛道 · 世界地标与 3D App 道具

2026-10-17。替换上一版默认浅绿天空和通用云岛，保留持续竞速、碰撞投递与同一座 Island 的核心循环。

## 美术与来源

远景直接使用 `sill-skin-packs` 的 World Landmarks 十组 `background-night.png`，转换为网页用 WebP，全部约 776 KiB。背景为完整的夜景画作，按行进距离交替，不能退化成单色默认天空。叠加深靛蓝遮罩保持标题和 Island 可读，未添加浅绿色环境雾。

赛道两侧生成十处立体地标：埃菲尔铁塔、富士山、吉萨金字塔、悉尼歌剧院、伦敦塔桥、泰姬陵、长城、自由女神像、圣托里尼蓝顶教堂、里约基督像。以已有背景的地标和夜间配色为依据，用程序几何创建可从不同视角看见厚度的模型；结构在生成后按材质合并，之后复用固定十组模型。

本轮没有调用图像生成服务。背景来源是项目已有生成画作，周边模型是新编写的程序几何。模型简化为游戏场景的轮廓表达，不声称是测绘级复原。

## App 图标道具

直接复制当前 App `Assets.xcassets/PluginIcon*.imageset/*.svg` 中的 Files、Photo、Pomodoro、Translate、Clipboard、QuickNote、Apps 等彩色图标。底部入口、飞行物和 Island 内对应图标共用这组原始资源。

赛道道具按每张 SVG 的 path / circle / rect 生成真实挤出几何：厚边、圆角、凸起的分层图形、明亮颜色和缓慢转动。参考马里奥式拾取道具的体积与反馈，角色、图标和品牌图形仍全部来自 Sill。没有套用问号箱贴图，也没有更换工具含义。

道具模板共享几何和材质，拾取销毁时只移除克隆及独立光环。文件和照片仍进入置物岛；工具仍切换原先对应的 Island 状态。

## 动态与资源边界

- 背景解码完成后再交叉淡入；请求带 generation，过期解码不会覆盖新的目的地。
- 背景缓存最多三组，模型固定十组，道具模板固定七组；没有按每次循环累加模型。
- 道具转动、背景交接、赛道、pet 和飞行共用同一模拟时间。暂停、后台及 Reduce Motion 均停止持续更新。
- 小屏保留彩色道具和地标夜景，隐藏周边模型标签以减少覆盖。
- 原生 Island 场景包及其 pointer-only 渲染合同没有改动。本轮编辑的是用户明确要求持续运动的网站 3D 原型。

资产来源、校验和及输出尺寸记录在 `prototype-world-assets/world-tour-sources.json`。

验证计划：桌面与手机截图；全部七种彩色道具自然碰撞；全部十处背景轮转；暂停时物体旋转和背景过渡冻结；后台与 Reduce Motion；循环后 geometry / texture 数量有界；无 JS 异常及缺失资源。证据保存到 `docs/design-previews/world-tour-20261017/`。

## 地标落地感调整

根据“周围地标悬浮、不踏实”的反馈，去掉每座建筑下方的倒锥圆台和发光圆环，用一片沿赛道延伸的连续深靛蓝地面承托地标。地面使用低对比纹理，远端和两侧逐渐融入原有夜景。地标跟随地形高度，取消道路侧倾对建筑高度的影响。

地标仍以固定模型循环复用，不增加上下漂浮动画。铁塔补充柱脚，长城下增加连续山脊，圣托里尼高处的房屋补齐基础、阶梯补齐立面，让建筑的支撑关系可见。彩虹赛道和道具保留轻盈、持续运动的表现。

地形只创建一个固定网格和一张程序纹理，在现有动画循环内更新，继续服从暂停、后台和 Reduce Motion 的统一策略。当前截图及专项验证保存在 `docs/design-previews/grounded-landmarks-20261017/`；此前世界巡游截图代表调整前版本。
